# Bose 3-2-1 IR Controller for Raspberry Pi 5

Небольшое Python-приложение с графическим интерфейсом для Twister OS, которое управляет музыкальным центром Bose 3-2-1 через инфракрасный светодиод на GPIO.

По умолчанию приложение запускается в тестовом режиме, чтобы можно было спокойно отладить интерфейс без подключенного ИК-железа.

## Что умеет

- Кнопка `Power On`
- Кнопка `Volume +`
- Кнопка `Volume -`
- Переключение `test/live mode` прямо из интерфейса
- Журнал отправленных или симулированных команд
- Отправка ИК-команд через `ir-ctl` и Linux-устройство `/dev/lirc0`

## Почему используется `ir-ctl`

Для Raspberry Pi 5 это надежнее, чем пытаться генерировать несущую 38 кГц из Python вручную. Передачу делает драйвер Linux, а Python отвечает только за интерфейс.

## Файлы

- `app.py` - графическое приложение на `tkinter`
- `bose_ir_config.json` - ИК-коды и путь к LIRC-устройству

## Подключение ИК-светодиода

Рекомендуется подключать ИК-светодиод не напрямую к GPIO, а через транзистор.

Минимальная схема:

- GPIO18 Raspberry Pi -> резистор -> база транзистора
- коллектор транзистора -> катод/цепь ИК-светодиода
- анод ИК-светодиода -> питание через токоограничивающий резистор
- общий GND обязательно объединить

Прямое подключение ИК-светодиода к GPIO нежелательно.

## Настройка Twister OS / Raspberry Pi OS

1. Установить пакет:

```bash
sudo apt update
sudo apt install -y v4l-utils
```

2. Включить overlay для ИК-передатчика.

Откройте `/boot/firmware/config.txt` и добавьте:

```ini
dtoverlay=gpio-ir-tx,gpio_pin=18
```

Если в вашей системе используется `/boot/config.txt`, добавьте строку туда.

3. Перезагрузить Raspberry Pi:

```bash
sudo reboot
```

4. Проверить, что устройство появилось:

```bash
ls /dev/lirc*
ir-ctl --features -d /dev/lirc0
```

## Запуск

```bash
python3 app.py
```

## Тестовый режим

По умолчанию в [bose_ir_config.json](/Users/aleksejsavcenko/Documents/CODEX/REMOTE/bose_ir_config.json) включен:

```json
"test_mode": true
```

В этом режиме кнопки работают, интерфейс обновляет статус и пишет команды в журнал, но реальная ИК-передача не выполняется.

Когда приедет плата передатчика/приемника, можно:

- выключить тестовый режим в интерфейсе
- или поставить `"test_mode": false` в конфиге

## Изменение ИК-кодов

Файл `bose_ir_config.json` позволяет задавать команду двумя способами.

Вариант 1, scancode:

```json
{
  "protocol": "nec",
  "scancode": "0x887703FC"
}
```

Вариант 2, raw pulses:

```json
{
  "protocol": "raw",
  "raw": [9000, 4500, 560, 560, 560, 1690]
}
```

`raw` задается в микросекундах, по очереди: импульс, пауза, импульс, пауза.

## Откуда взяты стартовые коды

Стартовые значения в `bose_ir_config.json` являются рабочей гипотезой на основе Bose IR-спецификации с NEC-подобным форматом и следующими кодами кнопок:

- `Volume Up`: `0x03`
- `Volume Down`: `0x02`
- `On/Off`: `0x4C`

Если конкретно ваш Bose 3-2-1 не реагирует, замените значения на снятые с вашего родного пульта.

## Полезная проверка без GUI

Можно отправить код напрямую:

```bash
ir-ctl --device /dev/lirc0 --send nec:0x887703FC
```
